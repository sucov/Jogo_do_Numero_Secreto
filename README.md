# 🚀 Jogo do Número Secreto

## 📌 Um Projeto Alura: Descobrir o número gerado aleatoriamente
Um projeto desenvolvido como metodologia de um curso da Alura, apresentando a criação e concepção de um jogo do zero.

---

## 🧩 Sobre o Projeto
- Primeiro projeto de programação do usuário;
- Um jogo divertido de se competir com amigos ou familiares;
- Utiliza de linguagens simples, sendo uma introdução pertinente ao universo da programação.
